# simple-tetris-in-C
This is a simple remake of Tetris made in C, with the purpose of learning the language.
It was tested with 3 platforms, Ubuntu, Windows 11 Pro and Windows 10. It may not work in other operating systems.
The compiler used for Ubuntu was gcc (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0, and the compiler used for Windows 10/11 was gcc-16.2.0-mingw-w64ucrt-14.0.0-r3. Other compilers may not work.
